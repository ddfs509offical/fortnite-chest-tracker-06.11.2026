События

Островок шлёт POST на этот адрес. Он же — «хаб»: F1 на ПК включает трекинг (полоса заливает островок) и выключает его обратно в хаб.

{"tier":"common"}                  // открыт обычный сундук  (цвет не важен)
{"rarity":"epic"}                  // то же, в другой записи
{"type":"chest"}                   // сундук без деталей
{"type":"connected"}               // старт матча / трек активен
{"type":"disconnected"}            // матч закончился
Проверка с ПК: curl -X POST …

Ключ F1 переключает трекинг глобально (работает и когда фокус в Фортанайте).
